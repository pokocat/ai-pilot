## 0. 一句话方法论

**先立哲学，再作表达。** 不要一上手就排版：先为这一张海报写出一套可被人读懂的美学立场
（它信什么、拒绝什么、如何用空间与色彩说话），再把这套立场翻译成画面。
哲学决定气质，模板只负责秩序；跳过哲学直接套模板，出来的就是「模板感」。

工作流分两段，服务端严格按序执行，中间产物落库可追溯：

1. **阶段一 · 视觉哲学**（文本产物）：给这张海报一个美学立场；
2. **阶段二 · 视觉表达**（图像 + 排版产物）：主视觉按哲学生成，文字由渲染器确定性排版。

## 1. 阶段一：视觉哲学怎么写

### 1.1 产物形态

- **命名运动**：1–2 个词的中文名（如「几何静默」「纸墨秩序」「留白宣言」），像一场小型美学运动的名字，
  不要出现产品名、客户名、行业名，也不要写成形容词堆叠。
- **哲学正文**：4–6 段，每段 2–4 句。总量克制——它是给下一步用的指令，不是散文比赛。
- **禁止**在哲学里写具体版式（「标题放左上」「用三栏网格」），那是模板与渲染器的职责。
  哲学只回答「气质与取舍」，把执行空间留给下一步。

### 1.2 六个必须回答的维度

每个维度**只讲一次**，不要在多段里反复重申同一件事（上游原则：避免冗余）：

| 维度 | 要回答的问题 |
|---|---|
| 空间与形 | 画面靠什么结构说话：块面、网格、轴线，还是大面积虚空？ |
| 色彩与材质 | 有限色板如何承担信息；纸感/墨迹/金属/哑光如何服务可信度。 |
| 尺度与节奏 | 什么被放到极大，什么被压到极小；重复与间隔如何形成呼吸。 |
| 构图与平衡 | 对称还是失衡；张力从哪里来，视线如何被引导。 |
| 视觉层级 | 第一眼看到什么，第二眼看到什么，第三眼才发现什么。 |
| 工艺感 | 哪些细节体现「这是被反复打磨过的」——对齐、留白收口、字距、边缘处理。 |

### 1.3 工艺感必须被反复强调

上游最重要的一条：成品要**看起来像花了很久、由这一行最顶尖的人反复打磨**过。
哲学正文里要多次落到这个要求上——「精工细作」「反复推敲的结果」「专业级执行」「每一处对齐都是选择」。
这不是修辞，它是给下一步的质量下限：任何「一眼像自动生成」的画面都不合格。

### 1.4 商业耦合（军师改编，上游没有）

上游面向纯艺术创作，本项目服务商业转化，所以哲学必须能承接一件事：

- 哲学要与 `PosterBrief.goal`（商业目标）和 `audience`（目标客群）**气质一致**：
  面向投资人的发布海报与面向社群的活动海报，不该共享同一套美学立场；
- 哲学**不写**卖点原文，也不替客户决定文案——文案是 brief 的事；
- 若 brief 的信息量明显超出一张海报（多目标、多 CTA、卖点 > 3），
  哲学阶段就要给出「建议拆成多张」的判断，而不是靠缩小字号硬塞。

## 2. 阶段二：视觉表达怎么落

### 2.1 视觉优先，文字极少（上游第一原则）

一张海报 ≈ **90% 视觉 + 10% 必要文字**。文字是视觉元素，不是段落容器。
允许的文字只有：主标题、副标题、最多 3 条卖点、1 个 CTA、身份落款、合规与 AI 标识。
**没有正文段落，没有项目介绍，没有把咨询报告压缩成海报。**

文字的音量由场景决定：招募/发布可以是有力的大字排印，专业服务/高端品类多为克制小字。
但无论音量大小，铁律不变——**不出画、不重叠、不压到安全边距以内**，每个元素都有呼吸空间。

### 2.2 职责边界：图片模型不写中文

这是本项目相对上游最硬的一条改动（方案 §4.1）。

- **图片模型只负责**：人物形象、背景场景、光影、构图、材质、以及**预留出来的留白区**；
- **确定性渲染器负责全部文字与可扫元素**：中文主副标题、卖点、姓名身份、Logo、二维码、
  联系方式、合规声明、品牌落款、AI 生成内容标识。

理由：图片模型仍会生成错字与伪文字；二维码必须真能扫；Logo 不能变形；
用户只改一句文案时不该重跑图片模型；固定排版才能稳定控住安全边距、字号与信息层级。

因此，写给图片模型的提示词里**不要出现任何要它渲染的字符串**，
而要明确要求它「在指定区域留出干净的负空间供后续排版」。

### 2.3 留白与层级

- **留白是结构，不是剩下的地方**。先决定虚空占多少、放在哪，再安排实体。
- 层级只做三层：**主（一眼）→ 次（第二眼）→ 辅（凑近才看）**。
  三层之外的信息不是「再小一点」，而是**删掉或拆到另一张**。
- 尺度对比要敢做：主标题与辅助信息之间不是差两号字，而是差一个量级。
- 收口处最见工艺：边距一致、基线对齐、字距成组、二维码与落款不像事后贴上去的。

### 2.4 原创，不模仿在世艺术家（法务红线）

**不接受「完全照某位在世艺术家/摄影师/设计师的风格复制」这类要求**，也不把「复制某人作品」
作为生成条件。命中此类请求时，转译为对视觉属性的描述，或直接拒绝该条方向。

可以表达的视觉属性（安全表述示例）：几何秩序、编辑设计与杂志排印、东方留白、
纸张与墨迹质感、纪实商业摄影、高端封面感、克制的品牌海报。

判定口径：描述**画面属性**（结构/色彩/材质/光线/构图）是允许的；
指名要求**复刻某个具体在世创作者或其作品**是不允许的。
`negativePrompt` 里的排除项同样只写属性，不写人名。

### 2.5 隐性主题（上游 "subtle reference"，本项目降权保留）

上游要求把主题作为「只有懂的人才会心一笑」的隐晦线索织进画面。
本项目保留这份克制的巧思，但**优先级低于商业清晰度**：
海报的第一职责是让目标客群三秒内看懂「这是什么、为什么可信、下一步做什么」。
隐性线索只能藏在纹理、色彩关系、重复母题这类不影响读取的层里，
**不得**牺牲主标题可读性、CTA 显著性或二维码可扫性去换取「艺术性」。

## 3. 服务端硬约束（上游没有，必须遵守）

1. **画布**：MVP 只出 3:4（540×720 @2x → 1080×1440 PNG）。比例不由模型决定。
2. **模板**：只认白名单 `person_hero`（人物主视觉）/ `editorial`（编辑杂志）/ `business_launch`（商业发布）。
   无效或缺失一律按 `scene` 回退默认模板——推荐是提示词的事，兜底是服务端的事。
3. **字体**：只用镜像内置的开源 OFL 字型栈（`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif` 风格），
   **不下载字体、不访问网络、不读写文件**（上游的 `./canvas-fonts` 与下载步骤在本项目不适用）。
4. **AI 标识**：海报角落固定标注 AI 生成，默认开启，只可调样式不可关闭。
5. **交付物**：MVP 只交 PNG。哲学文本是任务中间产物，落库可追溯，不作为对外交付件。
6. **失败不阻塞**：哲学生成失败或未配置模型时，回退确定性模板哲学继续出图；
   未配置图片供应商时走「无主视觉」纯排版路径，不报错。
7. **品牌口径**：所有对外文案与提示词一律用「军师参谋部 / Junshi Strategic Staff」；
   不得暗示与任何上游厂商存在官方合作（见 `NOTICE.md`）。

## 4. 自检清单（渲染前后各过一遍）

- [ ] 哲学是否只讲气质与取舍，没有替模板做版式决策？
- [ ] 六个维度是否各讲一次，没有互相重复？
- [ ] 工艺感是否被反复要求，而不是只提了一句？
- [ ] 文字是否收敛到「1 主标 + 1 副标 + ≤3 卖点 + 1 CTA + 落款」？
- [ ] 给图片模型的提示词里是否**没有**任何待渲染的字符串，并明确要求留出负空间？
- [ ] 是否存在指名复刻在世创作者的表述？（有则改写为属性描述或拒绝）
- [ ] 三层层级是否清晰，主次尺度是否差出量级？
- [ ] 留白是否是主动设计的结构，而不是排完剩下的空地？
- [ ] 是否有元素出画、重叠、压安全边距？二维码是否完整可扫、Logo 是否未变形？
- [ ] AI 生成标识是否在位？
- [ ] 信息量是否超载到该建议拆成多张？
