## 附：高频 AI 味词替换表

| AI 味词 | 替换建议 |
|---------|---------|
| 生成 | 出、做、写、帮我 |
| 认可 | 认、就按这个来、这个判断我认 |
| 同步 | 同步到（保留，但尽量少用）；用"更新到"、"跟着变" |
| 沉淀 | 留档、存档、放在这里 |
| 推演 | 根据实际情况的说法，无需统一替换 |
| 校准 | 参考、对照、调整 |
| 调用 | 引用、用上 |
| 解锁 | 启用、开通 |
| 显示在这里 | 就有了、会出来 |
| 待生成 | 还没出、还没有 |
