为什么门槛必须降到 960
你截图那个窗口实测约 1008pt 宽（图 2016px ÷ 2x，手机栏 405pt）。 按现在 1100 的门槛，默认窗口根本进不了双栏档 —— 双栏做了也白做。 960 这个数是倒推出来的：72 导航 + 320 副栏 + 24 间距 + 40 页边距 = 456，留给主栏 504px， 刚好还能放下一张完整的军令卡。再低就该退回单栏。

主栏 = 窗口 − 456（72 导航 + 40 页边距 + 24 栏间距 + 320 副栏）。窗口再大，容器就撞上 1240 封顶、 主栏定格 896，栏内正文轴 840 左右各留 28 —— 正文行长在任何显示器上都一样。
分栏语法（五个 tab 统一）
主栏 = 你要读、要动的那一件事
副栏 = 支撑它成立的上下文
唯一例外是问策：它的副栏是导航（选军师、选会话），所以放左边，与其余四个 tab 的右副栏相反。 这正是桌面软件的通例 —— 导航在左、上下文在右。
