设 计 标 注
  1. 1懂你卡无冷启动门槛——这是给新用户的第一根进度条，段位卡还没资格出现时它就在。
  2. 2进度条为直角细条：--surface-2 底 + 1px 线，填充走 accent-deep → accent 渐变，不做发光。
  3. 3对外一律中文成数，禁 percent 表述；分值仅在构成明细里以「已得/上限」出现。
  4. !口径待定稿：规格 §4.2 档位表把 40-59 记作「五成」，需求文案写「三成」。视觉稿按需求文案示意，落地前请敲定成数映射。
  5. 4本屏两段刻意取相邻两刻：懂你卡示意 50 档解锁前（差 3 次复盘），密报架示意刚跨过 50 档、火漆未启，以便一屏看全三种卡态。
  6. 5密报架三态：封印灰卡（灰底 + 方形「封」+ 差值）、火漆待启卡（accent-soft 底 + 火漆小印）、已启卡（白底 + 方形勾 + 可重读）。
  7. 6解锁不自动弹出，保留「拆封」仪式；样本不足时如实说「这份还差些火候，再攒 N 次复盘」。
  8. 7只升不降（取历史峰值），六行明细各带「一句怎么涨」，把目标梯度写在明面上。
  9. 8复盘/回填/揭封完成后 toast 追加一行小字「军师对你的了解 +2」，与本页数字同源。
视觉规范自检 —— 全稿卡片 / 按钮 / 容器 border-radius 一律 0（唯一圆形为火漆印，实体印章）； 字体全走宋体栈，字重不过 600；色值全部取自 app/src/app.scss token，未引入新色（金 #A07D2C 取自 theme-gold 的 --accent）； 单文件、无外部字体 / 图片 / 脚本，图形（签筒、信封、火漆、印章、进度条）皆由 CSS 绘成。
文案口径 —— 军师语感，禁「打卡 / 签到 / 开奖 / get」；数字铁律：只引真实账本，样本不足如实说、不报百分比。
建设顺序 —— #5 今日攻守签 → #1 预言揭封 → #10 懂你指数 → #3 章回连载（先立日活锚点，再立应验事件，再资产化，最后长线剧情）。
